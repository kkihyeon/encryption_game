키 순서 암호화
원문을 키의 자릿수 크기만큼 단위로 자른 뒤, 각 단위의 글자를 키 숫자가 나타내는 순서로 재배열합니다.
키 입력: 순열 숫자 (예: 21, 312, 4132) — 각 자릿수는 1~n 범위의 중복 없는 위치 번호
원본: ABCDE   키=312 (자릿수 3 → 3글자씩 자름)
1번째 단위 [A B C] → 3위=C, 1위=A, 2위=B → C A B
나머지 [D E] → 키 자릿수(3)보다 짧아 순서 그대로 → D E
→ 암호문: CABDE

대칭 에너그램 암호화
원문을 키값 크기의 단위로 자른 뒤, 각 단위를 역순으로 뒤집습니다. 키 값보다 짧은 단위의 문장이 남는 경우 그대로 둡니다. 복호화는 암호화와 같은 방법(각 단위를 다시 역순)으로 수행합니다.
키 입력: 단위 크기 (정수, 권장 2–10) — 예: 키=3 → 3글자씩 단위로 역순
원본: HELLO   키=3
단위 1: [H E L] → 역순 → L E H
단위 2: [L O] → 유지 → L O
→ 암호문: LEHLO

키 입력: 이동(시프트) 칸 수 (1–25) — 예: 키=3 → A는 오른쪽 3칸 → D
원본: ATTACK   키=3
A→D, T→W, T→W, A→D, C→F, K→N
→ 암호문: DWWDFN

행렬 스키테일 암호화
고대 그리스의 암호 도구에서 유래한 방식입니다. 눕힌 막대기 옆면을 행으로 보고 막대기에 감은 종이들을 열로 봅니다. 메시지를 키값(열 수,감은 종이 횟수)으로 이루어진 격자에 가로(행) 방향으로 채운 뒤, 세로(열) 방향으로 읽어 암호문을 만듭니다. 마지막 행이 다 채워지지 않으면 빈 칸은 건너뜁니다. 암호문 길이는 원본과 동일합니다.
키 입력: 열 수 (2–10) — 예: 키=4 → 4열 격자 사용
원본: HELLOWORLD (열=4, 10글자 → 4×3 격자)
격자: H E L L / O W O R / L D _ _
세로 방향으로 읽기: → HOL·EWD·LO·LR
▸ 빈 칸(_)은 건너뛰므로 암호문은 10글자 그대로
→ 암호문: HOLEWDLOLR
